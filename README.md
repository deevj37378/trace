# Trace — landing page redesign

A redesign of [gettrace.dev](https://gettrace.dev) built with Next.js. The copy is the same as the original site; the design and animations are new.

## Pages

- `/` — homepage
- `/desktop` — Mac notch demo and waitlist
- `/docs` — documentation overview
- `/pricing` — credit calculator and FAQ

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion · Lenis
